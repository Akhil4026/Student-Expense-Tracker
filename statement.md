# Project Statement

## Project Title
Student Expense Tracker

## Problem Statement
Students often find it difficult to keep track of their daily expenses.
Manual tracking can lead to poor budgeting and lack of awareness of spending habits.

## Scope
The project provides a simple Java-based application to record,
view, search, delete, and calculate student expenses.

## Target Users
- College students
- Hostel students
- Students managing monthly budgets

## High-Level Features
- Add expenses
- View expenses
- Search by category
- Delete expenses
- Calculate total spending
- Save data using file handling
